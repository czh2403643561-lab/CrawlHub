# CrawlHub - AI 页面结构分析与数据采集助手

- 项目是什么：运行在本地浏览器环境中的 Chrome 插件，提供页面分析模式和数据采集模式
- 解决的需求：帮助开发者理解页面数据在哪里、页面如何组织、字段对应哪些元素，以及是否存在结构化数据或接口线索
- 核心功能：页面分析模式生成取证报告；数据采集模式为后续规则生成、列表提取和导出提供基础入口
- 页面分析模式：元素选择、DOM 结构分析、数据来源线索分析和 `analysis.json` 报告生成
- 数据采集模式：根据页面分析结果逐步生成采集规则；当前仅提供基础框架，不执行实际采集
- 当前阶段目标：保留页面分析能力，同时建立双模式交互，为后续采集规则开发准备入口
- 使用方式：在隔离浏览器中打开目标页面，点击插件打开悬浮面板；切换到页面分析模式进行取证，或切换到数据采集模式查看后续能力入口
- 面板操作：支持持续显示、最小化和关闭；面板显示采样状态、元素数量和字段摘要
- 元素分析：输出标签、class、id、selector、XPath、文本、父级结构、附近兄弟节点和通用字段类型推测
- 网络分析：可监听启动监听后的 fetch/XHR 请求，仅记录脱敏 URL、方法和响应元信息，不记录响应内容
- 数据约束：数据只在本地处理；不上传账号信息、不保存 Cookie、不模拟用户行为、不自动登录、不针对单个平台写死规则
- 暂不开发：TikTok 专用字段解析、自动翻页、自动采集、Excel 导出
- 运行说明：在 Chrome 的“扩展程序”页面开启开发者模式，选择“加载已解压的扩展程序”，指向本项目目录
