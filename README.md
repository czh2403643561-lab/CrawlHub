# CrawlHub

- 项目是什么：运行在本地浏览器环境中的 Chrome 插件，用于分析 TikTok Shop 卖家后台页面结构
- 解决的需求：为后续商品数据采集功能识别页面结构与可能的数据来源
- 核心功能：获取当前页面 DOM，分析商品列表，识别 DOM、内嵌 JSON 和网络接口线索，导出 JSON 分析报告
- 第一阶段：输出页面基本信息、DOM 摘要、图片资源、文本节点、表格/列表结构、可疑 JSON 数据和后续采集建议
- 使用方式：登录 TikTok Shop 卖家后台，打开热卖商品榜页面，点击插件并导出页面分析报告
- 数据约束：所有数据本地处理；不上传页面数据、不保存账号信息、不模拟人工操作、不自动登录
